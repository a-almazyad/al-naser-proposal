# Al Naser Family App Proposal

A bilingual, presentation-style HTML proposal prepared by Abdullah Alamzyad.

Live site: https://a-almazyad.github.io/al-naser-proposal/

## Controls

- Use the arrow buttons or keyboard arrow keys to move between slides.
- Use the language button to switch between English and Arabic.
- Use the grid button to jump directly to a slide.
- Use the print button to save a landscape PDF.
